Is this really a digital twin?
A digital twin is a model of a specific real system, kept honest by real measurements and used to predict something about it. This qualifies because the leakage model is built from the real AES datapath (power ∝ bits that flip), it reproduces the measured signal-to-noise ratio (~0.015) of real chip datasets (ASCAD / AES_HD), and it matches a Verilog RTL implementation byte-for-byte — then it's used to decide how attackable a design is before it's manufactured. Scope, stated plainly: this is a pre-silicon / design-time twin (standard in chip design), not one streaming live telemetry from a physical chip; and this page is the live simulation front-end — the “twin” credibility comes from that validation work, not the animation alone.
