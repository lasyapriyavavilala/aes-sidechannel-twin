A model built only from the AES datapath predicts the power a real chip leaks, and an attacker turns that leakage back into the secret key. Everything below is driven by real data: the register states, the per-cycle bit-flips, the measured SNR, and a template attack converging to the true key byte. Press play.

Each clock the register is overwritten; a CMOS register burns power in proportion to the number of bits that flip (its Hamming distance). The final round is the leak the attacker uses.
